## Versioning Policy

BaseKitではSemantic Versioningを参考にバージョン管理を行う。

### Major Version

設計思想やConstitutionの大幅な変更を伴う場合。

例

1.x → 2.x

---

### Minor Version

新章追加、大規模な追記、Architectureの発展など。

例

1.0 → 1.1

---

### Patch Version

誤字修正、表現改善、軽微な追記。

例

1.0.0 → 1.0.1

---

## Constitution Evolution

BaseKit Constitutionは固定文書ではない。

新しい知見、実証結果、AI技術の進化、コミュニティからの提案を反映しながら継続的に更新する。

ただし、以下の原則は維持する。

* Coreを小さく保つ
* Plugin中心の設計
* Documentation First
* AI Collaboration
* Community Driven Development

---

## Historical Note

Version 1.0.0は、AIとの共同開発によって作成された最初のBaseKit Constitutionである。

本版は、実証プロジェクトおよび継続的な改善の出発点として位置付けられる。
