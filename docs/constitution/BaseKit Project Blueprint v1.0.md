# BaseKit Project Blueprint v1.0

## 第1章 Project Overview

---

# 1.1 プロジェクト概要

BaseKitは、AI時代のソフトウェア開発を前提として設計された、プラグイン方式によるOSS（オープンソースソフトウェア）開発基盤である。

本プロジェクトは、個人開発者、フリーランス、小規模開発会社が、中小企業向け業務システムや各種アプリケーションを効率的に開発できる共通基盤を提供することを目的とする。

BaseKit自体は完成された業務システムではない。

認証、設定管理、イベント管理、ログ、権限管理、プラグイン管理など、多くのシステムで共通して利用される基盤機能のみを提供し、個々の業務ロジックは独立したプラグインとして実装することを基本方針とする。

これにより、共通部分を再利用しながら、用途に応じた柔軟なシステム構築を可能にする。

---

# 1.2 開発背景

本プロジェクトは、宝くじ予想システムの開発を通じて得られた経験から始まった。

当初は個別システムとして開発を進めていたが、実装を重ねる中で、認証、設定管理、ログ、データ管理など、多くの機能が他のシステムでも共通して必要になることに気付いた。

その後、CRM、個人業務効率化ツールなど複数のシステム設計・開発を進める中で、さらに共通化できる機能が増え、「個々のシステムを作るより、再利用可能な基盤を整備した方が効率的である」という考えに至った。

BaseKitは、この経験から生まれたプロジェクトである。

---

# 1.3 プロジェクトの目的

BaseKitの目的は、業務システムそのものを提供することではない。

目的は、様々な業務システムを効率よく構築できる共通基盤を提供することである。

具体的には以下を目指す。

* 再利用可能なCore機能の提供
* 拡張可能なPluginアーキテクチャ
* AIとの共同開発を前提とした設計
* 仕様書中心の開発プロセス
* OSSとして継続的に発展可能な基盤の構築

---

# 1.4 開発の前提

BaseKitは、一人ですべてのシステムを開発することを前提としていない。

本プロジェクトは、開発者一人ひとりが持つ時間や知識には限界があることを前提として設計されている。

そのため、Coreは必要最小限に保ち、各業務機能はプラグインとして独立させることで、誰でも自由に機能追加や拡張ができる構造を採用する。

また、本プロジェクトではAIを開発パートナーとして積極的に活用し、仕様策定・実装・レビュー・改善の各工程に取り入れることを基本方針とする。

---

# 1.5 対象利用者

BaseKitは、以下のような開発者を主な対象としている。

* 個人開発者
* フリーランス
* 小規模開発会社
* AIを活用したシステム開発を行う開発者
* 中小企業向けシステムを短期間で構築したい開発者

業種は限定しない。

CRM、SNS、業務管理、会計、分析システムなど、多様な用途で利用できることを目指す。

---

# 1.6 BaseKitが提供するもの

BaseKitが提供するのは、あくまで開発基盤である。

主な提供内容は以下とする。

* BaseKit Core
* Plugin Framework
* Plugin SDK
* BaseKit Specification
* Plugin Specification
* Official Sample Plugins
* 開発ガイドライン
* AI共同開発ガイド

これらをOSSとして公開し、誰でも利用・改良・拡張できる環境を提供する。

---

# 1.7 本Blueprintの位置付け

本Blueprintは、BaseKitプロジェクト全体の設計思想、開発方針、および実装指針を定義する最上位文書である。

各種仕様書（Specification）、設計書（Architecture）、実装ガイド（Development Guide）は、本Blueprintを基準として作成される。

また、本Blueprintは将来的な機能追加やコミュニティによる拡張が行われる場合においても、一貫した設計思想を維持するための基準文書として位置付ける。

---

# 第1章まとめ

BaseKitは完成された業務システムを提供するプロジェクトではない。

共通基盤をOSSとして整備し、多様な業務システムを効率的に構築するための土台を提供することを目的とする。

Coreは必要最小限に保ち、業務機能はプラグインとして独立させる。

AIとの協調開発を前提とし、仕様書を中心とした開発プロセスによって継続的に改善される開発基盤を目指す。
